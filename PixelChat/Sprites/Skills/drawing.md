# Direct pixel drawing

Establish logical canvas, silhouette, palette and layer roles first. Read a reference or current PNG before drawing. Use a small palette and crisp integer geometry for pixel art. Separate accessories that need independent animation. Build silhouette, major color masses, shadow and highlights in one coherent batch or script.

Render at native scale to judge readability and at integer enlargement for local repairs. Read exact pixel regions when a one-pixel error is ambiguous. Respect layer locks and selection boundaries. Do not smooth-resize or introduce partial alpha in strict pixel mode. Painted artwork has different brush and resampling rules; conversion requires an explicit command.
