# Animation construction and repair

Define the clip's ordered phases, contact frames, timing, direction and loop policy. Preserve intended jumps, recoil, holds, squash and stretch. Use separate layers where accessories move independently. Pivots and named attachments record engine-facing registration points.

Inspect every frame using paginated contact sheets, enlarged crops where needed, and playback with saved durations. Inspect the last-to-first seam only for looping clips. Check identity, anatomy, facing, alternating foot contacts, phase progression, silhouette readability and accessory continuity as artistic judgments with frame references.

Dimension, alpha, palette, timing and duplicate checks are measurements. Centroid drift and size changes are heuristics, never automatic reasons to center or normalize motion. Repair only identified defects in a bounded batch; re-render affected frames and the relevant transition.
